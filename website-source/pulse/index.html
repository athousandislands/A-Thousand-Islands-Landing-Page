Pulse

Pulse began with a question: how could we make energy feel tangible on a screen? We wanted people to discover it through movement and voice.

We made a field of particles the centre of the interface. Using JavaScript, we built a system that translates hand gestures and voice input into changes in how the particles move.

The result is an interactive web experience that changes with the person using it. Each gesture or sound gives the particle field a different form.
