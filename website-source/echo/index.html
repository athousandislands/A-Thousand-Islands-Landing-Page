Echo

We built Echo to give live music a visual identity that can change with the set. An operator loads a collection of images and chooses a microphone feed or a music track.

Echo turns those images into a field of particles that gathers, breaks apart and forms again as it responds to the sound.

We wanted each performance to have room to move differently, while keeping a visual character you could recognise from one set to the next.

An early build looked too sparse at one particle per sampled pixel. We restored the 200,000-particle field and wrote custom GLSL shaders in Three.js to draw several particles from each sampled pixel. We sized the GPU textures to the data in each image and switched texture references during morphs, keeping the density without copying that data between transitions.
